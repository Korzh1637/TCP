# ==Лекция 1: Элементарные понятия и оценки выборки==
Объект - элементарная единица в анализе данных
все объекты обладают признаками.

Признак - измеримое свойство наблюдаемого объекта
Наблюдение - фиксация значений признаков у объекта
Все объекты расположены в пространстве координат-признаков. Координаты объекта в пр-ве признаков - признаки координат(?) объектов.
отображение объектов и признаков можно совместить
Алеф-0 (N0) - кардинальное число, отраж. мощность бесконечного счетного мн-ва
n <= N0
n + N0 = N0
N0 + N0 = N0
N0 * N0 = N0
Дробить можно не только целыми числами (при этом при расширении отраж. можность бесконеч. несчетных мн-в) (Алеф-1 (N1))
N1 > N0
N0 + N1 = N1
N1 + N1 = N1
2^N0 = N1

Алеф-2 (N2) - высшая
Из любой ф-ции можно сделать линейную (y = F(x)) (в какой-то гиперплоскости)
N2 > N1
N1 + N2 = N2
